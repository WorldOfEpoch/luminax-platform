Current framing

Underfoot is now being carried forward as a Unity game with Warbles, Bigguns, world-map routing, and role-shaped voice logic.

This board is the operator summary for what the game is, what changed in the engine plan, where the active files live, and which systems Luminax now tracks directly across Unity scenes, Meshy asset generation, and the world-service bridge.

Current state

Live status

Engine

Unity is now the active target

The old Unreal scaffold remains archived for reference, but the active implementation surface has moved to Unity and C#.

Website

Warble-first public site

The Underfoot site now explains the Unity scene flow, Warble/Biggun voice behavior, Meshy-backed menu art, and the active generated site-art lane.

Server

Authority still matters

The dedicated server plan still owns match rules, role slots, weighted carry, hole travel, rewards, and anti-cheat validation.

Assets

Meshy is part of the stack

Luminax now tracks Meshy-generated Warble/Biggun/prop work, UI image generation, import staging, and Unity-facing asset hookup as first-class project surfaces.

Verified surfaces

What exists right now

World service

world-service still serves the public site, maps, guest sessions, and MySQL-backed prototype persistence.

Unity scaffold

unity/Underfoot/Assets/Scripts now contains the active C# server, client, frontend, gameplay, and audio logic skeleton.

Scene flow

The startup scene, title scene, character select, game list, world map zone, and minigame routes are now explicit in the Unity frontend manifest.

Voice rules

Open mic only, no team voice, no text chat, Warble-to-Biggun speech replaced by unintelligible squeaky warbling.

Asset workflow

Meshy model generations, UI image outputs, import staging, and prefab hookup are now part of the tracked project workflow instead of side notes.
