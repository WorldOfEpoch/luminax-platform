What is being built

A Unity multiplayer game with explicit frontend scenes, server-first authority, and no-text-chat voice play.

Underfoot now targets Unity with C# scripts, and Luminax is tracking the full stack instead of only the old engine assumptions. The flow is clear: startup scene, title scene, character select, game list, world map zone, and minigame maps. The asset plan is equally explicit now: Meshy for creatures, props, and UI images, plus import staging and prefab hookup inside the Unity project.

Implementation order

Recommended sequence

01. Shared contract

Lock roles, voice rules, interaction verbs, scene IDs, and hole-travel rules in shared JSON and C# contracts first.

02. Server authority

Build the headless Unity match server, role slots, game list, respawn authority, weighted carry validation, and objective state.

03. Frontend scenes

Hook the startup scene, title scene, character select, and game list into the same manifest used by the runtime code.

04. Asset pipeline

Run Meshy model and UI-image generations, stage imports, and wire the resulting models/prefabs into the Unity frontend and gameplay scenes.

05. World map zone

Connect discovered holes, world-map movement, and minigame portal loads before expanding content scope.

06. Voice DSP

Ship readable proximity voice with occlusion, muffling, and the role-based Warble/Biggun receive rules.

07. Content pass

Bring in the real Warble and Biggun meshes, props, prefabs, hazards, and AI when the structure is stable.
